# Foco · demo Python + HTML

Demo local para Windows, hecha con Python estándar y HTML/CSS/JavaScript. No instala paquetes ni necesita una cuenta.

## Cómo abrirla

1. En GitHub, presiona **Code → Download ZIP** y descomprime el archivo.
2. Abre la carpeta descargada.
3. Haz doble clic en `Abrir Foco.bat`.
4. Se abrirá la demo en el navegador. Mantén la ventana de comandos abierta mientras la usas; para detenerla, presiona `Ctrl+C`.

Si Windows no reconoce `python`, instala Python desde [python.org](https://www.python.org/downloads/) y marca la opción para añadir Python al PATH durante la instalación.

También puedes abrir `index.html` directamente, pero para guardar el avance y los bloques de agenda debes iniciar `app.py`.

## Qué incluye

- Inicio con racha, puntos y agenda del día.
- Ramos y material ilustrativo con etiquetas de autorización.
- Ejercicios de selección múltiple con explicación.
- Simulacros distintos para Cálculo, Álgebra, Física y Programación.
- Agenda con bloques que puedes añadir, completar y borrar.
- Encuesta de perfil y temporizador Pomodoro.
- Mascota motivadora personalizable con razas Golden retriever, Husky, Yorkshire y mestiza; pestañas de color para perros y gatos, además de cabezas, cuerpos y accesorios. El modo foto es solo una simulación visual; no usa IA real ni procesa la imagen.
- Recompensa de muestra tras 50 ejercicios; no corresponde a un cupón universitario real.
- Los ajustes de la mascota son temporales y solo sirven para mostrar el prototipo visual.

La demo se enlaza solo a `127.0.0.1` en este computador. Para compartirla con otras personas habría que alojarla en un servidor.
